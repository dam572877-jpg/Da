# DREAM HOUSE — Classic Mobile V18

- Mobile-first classic executive redesign using a single V18 visual system.
- Floating vertical navigation remains on the right side on phones.
- Added a compact mobile quick-action bar for adding properties/clients and opening reports.
- Property PDF export now uses 6 property cards per page, so 10–12 selected properties are exported in one PDF across multiple pages instead of stopping at 4.
- Selected-property export still includes only the selected IDs and preserves selection across filtering.
- PDF/image report pagination is generated from the complete selected dataset; no hard 4-record report limit remains.
- Improved classic navy/ivory/champagne palette, mobile spacing, forms, modals and controls.
- JavaScript syntax validated with `node --check app.js`.
