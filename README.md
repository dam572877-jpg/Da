# DREAM HOUSE — Classic Executive V20

Mobile-first real-estate office system for GitHub Pages.

## GitHub Pages
1. Put the contents of this folder in the repository root.
2. Make sure `index.html` is in the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select the branch and `/ (root)`.
4. Open the generated Pages URL.

The project is static and uses browser storage for its demo data; no build step is required.
